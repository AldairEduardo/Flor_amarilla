## Descripción
Este proyecto es una animación interactiva realizada en **JavaScript** que celebra la tradición mexicana de regalar flores amarillas el 21 de marzo, marcando el inicio de la primavera. Inspirado en esta temática, busca demostrar habilidades en frontend utilizando HTML, CSS y JS. Las flores amarillas simbolizan amor, amistad, alegría y nuevos comienzos, transmitiendo energía positiva y optimismo a través de una experiencia visual atractiva.
